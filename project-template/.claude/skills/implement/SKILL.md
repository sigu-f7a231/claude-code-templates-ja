`docs/plan.md` のタスク「$ARGUMENTS」を実装してください。

## 手順

1. `CLAUDE.md`、`.claude/rules/`(コマンド・規約・作業ルール)、`docs/spec.md`、`docs/plan.md` の該当部分を読む。タスクが特定できなければ質問する。
2. 変更するファイルの周辺コードを読み、既存の規約・命名・構成に合わせる。
3. **指定されたタスクの範囲だけ**を実装する。範囲外の改善や整理はしない(気づいた点は報告に書く)。
4. 変更に対応するテストを追加・更新する。
5. `.claude/rules/commands.md` に書かれたテスト・lint のコマンドを実行し、結果を確認する。失敗したら原因を調べて直す。
6. `docs/plan.md` の該当タスクに、完了の印と簡単なメモを書く。
7. 次を報告する: 変更したファイルと理由、テスト結果、確認方法、気づいた点・未解決事項。

## 制約

- 既存ファイルの削除、設定ファイルの大きな変更、依存パッケージの追加は、実行前に確認する。
- 秘密情報をコードに書かない。
- コミットはしない(`/commit` で行う)。
