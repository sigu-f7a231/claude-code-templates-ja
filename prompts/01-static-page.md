# 静的ページを作ってください

## 概要

- ページの目的: 【例: 自己紹介 / イベント告知 / 資料の公開】
- ページ数: 【1ページ / 複数(ページ名: index, about ...)】
- 想定する閲覧者: 【誰が、どの端末で見るか】

## 内容

<!-- 文章・画像が未定なら「仮の文章でよい」と書く。仮の場合は明示してもらう -->
- セクション構成(上から順に):
  1. 【例: ヘッダー(ロゴ + ナビ)】
  2. 【例: メイン(見出し + 説明)】
  3. 【例: 本文】
  4. 【例: フッター(連絡先・コピーライト)】
- 文章: 【提供済み(場所: ○○)/ 仮の文章で作成】
- 画像: 【提供済み(場所: ○○)/ プレースホルダーで作成】

## 技術

- HTML5 + CSS(必要な場合のみ素の JavaScript)。フレームワーク・ビルドツールは使わない
- ファイル構成: `index.html` / `css/style.css` / `js/main.js` / `images/`
- CSS フレームワーク: 【使わない / Tailwind CDN など】
- 外部ライブラリは CDN で読み込む場合、バージョンを固定する

## デザイン

- 雰囲気: 【例: シンプル、余白多め、落ち着いた配色】
- 配色: 【メイン #○○○○○○ / アクセント #○○○○○○ / 未定なら提案】
- フォント: 【例: システムフォント / Google Fonts の ○○】
- スマホ表示: 【対応する(モバイルファースト)/ PC のみ】

## 品質要件

- セマンティックな HTML(`header` / `main` / `section` / `footer`)
- 画像に `alt`、見出しの階層を正しく、色のコントラストを十分に
- `<title>` と `meta description` を設定
- ブラウザで直接ファイルを開いて動くこと

## 完了条件

- [ ] すべてのページがブラウザで正しく表示される
- [ ] スマホ幅(375px)で横スクロールが出ない
- [ ] リンク切れ・画像切れがない
- [ ] 確認方法(ファイルの開き方、または簡易サーバーのコマンド)が示されている

## 進め方

1. 構成案(ファイル構成とセクション)を先に提示して、承認を待ってください。
2. 承認後に作成し、最後に確認手順を示してください。
