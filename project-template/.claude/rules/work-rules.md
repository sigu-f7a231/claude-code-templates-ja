# 作業ルール

- 1回の変更は、1つの目的にまとめる。
- コミット前に、テストと lint を通す。
- `git push` は人が行う(Claude は実行しない)。
- 既存ファイルの削除、依存パッケージの追加、設定ファイルの大きな変更は、実行前に確認する。
- 秘密情報(キー、パスワード、`.env`)はコードに書かず、コミットしない。
