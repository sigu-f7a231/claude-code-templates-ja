# ランディングページ(LP)を作ってください

## 目的

- 商品・サービス: 【名前と一言説明】
- コンバージョン(ゴール): 【例: 無料相談の申込 / 資料請求 / 購入 / メルマガ登録】
- 目標: 【例: 申込率 ○% / まずは公開して計測】

## ターゲット

- 想定する人: 【年代・職業・状況】
- その人の悩み・不満: 【具体的に2〜3個】
- 流入経路: 【例: 広告 / SNS / 検索】(スマホ比率が高いか)

## 訴求

- キャッチコピー案: 【あれば。なければ「3案提案してほしい」】
- 強み・差別化ポイント: 【3つまで】
- 実績・証拠(あれば): 【数字、導入事例、お客様の声、受賞歴】
- 価格・条件: 【記載する / しない】
- 注意事項・免責: 【例: 効果には個人差があります】

## ページ構成(上から順)

<!-- 不要なセクションは削除、順序は変更してよい。提案を求めてもよい -->
1. ファーストビュー(キャッチコピー + サブコピー + CTA ボタン + メイン画像)
2. 悩みの共感
3. 解決策・商品の紹介
4. 特長(3つ程度)
5. 利用の流れ(ステップ)
6. 実績・お客様の声
7. 料金
8. よくある質問
9. 最終 CTA(申込フォーム or ボタン)
10. フッター(会社情報・プライバシーポリシー・特商法表記)

## CTA(行動喚起)

- ボタン文言: 【例: 無料で相談する】(同じ行動には同じ文言を使う)
- 配置: ファーストビュー、中盤、最後。スマホでは画面下部に固定ボタンも検討
- 遷移先: 【フォーム / 外部フォーム URL / 電話 / LINE】

## フォーム(ある場合)

- 項目: 【氏名 / メール / 電話 / 相談内容 など。必要最小限に】
- 送信先・処理: 【例: Googleフォーム埋め込み / メール送信サービス / 未定(提案してほしい)】
- 入力チェックと完了メッセージを付ける

## 技術・デザイン

- 技術: 【HTML/CSS/JS のみ / 静的サイトジェネレーター / 未定(提案してほしい)】
- デザイン: 【ブランドカラー、雰囲気、参考 LP の URL】
- スマホファースト。アニメーションは控えめに(表示速度を優先)
- 画像: 【提供済み / プレースホルダー】。`alt` と遅延読み込みを設定

## 品質要件

- 表示速度: 画像を最適化し、不要な JS を入れない
- SEO / OGP: `title`、`meta description`、OGP 画像・タイトル・説明
- 計測: 【Google Analytics など。入れる/入れない】(入れる場合は同意の扱いも確認)
- アクセシビリティ: コントラスト、フォームのラベル、キーボード操作

## 完了条件

- [ ] 上記の全セクションが PC・スマホ(375px)で崩れない
- [ ] CTA がすべて正しい遷移先に飛ぶ
- [ ] フォームが期待どおり動く(入力エラー・完了表示を含む)
- [ ] 確認方法が示されている

## 進め方

1. まず「ターゲット・訴求・構成」を整理した案と、コピー案(キャッチコピー 3 案)を提示して承認を待ってください。
2. 承認後に実装し、最後に確認手順を示してください。
