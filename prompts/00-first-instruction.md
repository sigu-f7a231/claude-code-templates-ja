# 最初の指示

## 作るもの

- 種類: 【静的ページ / LP / HP / Web アプリ / レスポンシブ Web アプリ / スマホアプリ(Flutter) / ネイティブアプリ】
- 名前: 【プロジェクト名】
- 一言で言うと: 【何を、誰のために作るか】

## 目的とゴール

- 目的: 【なぜ作るか。例: 問い合わせを増やしたい】
- 完成の定義: 【何ができたら完成か。例: 本番に公開でき、スマホで崩れない】
- 期限・規模: 【例: 1週間 / まずは最小限(MVP)】

## 前提・環境

- 作業ディレクトリ: 【例: このフォルダ(空)/ 既存リポジトリ】
- 使える技術・使いたい技術: 【例: HTML/CSS/JS のみ / Next.js / Flutter / 未定(提案してほしい)】
- 使えない技術・制約: 【例: ビルド不要にしたい / 有料サービスは使わない】
- 公開先: 【例: GitHub Pages / Vercel / 未定】

## 進め方(この順で進めてください)

1. **まず質問してください。** 不明点や決めるべきことがあれば、実装前に最大5個まで聞いてください。
2. **計画を出してください。** ディレクトリ構成、使う技術、作業の順序(小さなステップに分割)を提示し、私の承認を待ってください。承認前にファイルを作成・変更しないでください。
3. **小さく作り、都度確認してください。** 各ステップの終わりに、動作確認の方法(コマンドや開き方)を示してください。
4. **変更点を要約してください。** 作成・変更したファイルと、その理由を短くまとめてください。

## 守ってほしいこと

- 既存のファイルを削除・上書きする前に確認してください。
- 秘密情報(API キー、パスワード)をコードに直接書かず、環境変数を使ってください。
- 分からないことは推測で進めず、質問または「未確認」と明記してください。
- 説明と回答は日本語でお願いします。
