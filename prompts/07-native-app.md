# ネイティブアプリを作ってください

## 概要

- アプリの目的: 【誰の、どんな課題を解決するか】
- 対象 OS: 【iOS のみ / Android のみ / 両方(別々に実装)】
- 最低対応バージョン: 【例: iOS 17 / Android 10(API 29)】
- なぜネイティブか: 【例: OS 固有 API を使う / 性能 / OS の標準 UI に合わせたい】
- 配布: 【個人 / 社内 / ストア公開】

## 開発環境(最初に確認してください)

- iOS: 【Xcode のバージョン、Mac の有無、Apple ID / 開発者アカウント】
- Android: 【Android Studio のバージョン、エミュレーター / 実機】
- 足りない環境があれば、導入手順を案内してください

## 技術

- iOS: 【Swift + SwiftUI / UIKit】、アーキテクチャ【MVVM など / 提案してほしい】
- Android: 【Kotlin + Jetpack Compose / View】、アーキテクチャ【MVVM + Repository など / 提案してほしい】
- 依存管理: 【Swift Package Manager / Gradle(バージョンカタログ)】
- ライブラリ追加時は、用途・メンテ状況・ライセンスを確認してから導入する
- 両 OS の場合: API とデータ仕様を共通化し、UI と挙動は各 OS の標準的な作法に合わせる

## 機能要件

| 機能 | 内容 | 優先度 |
|---|---|---|
| 【ログイン】 | 【方式】 | 【必須】 |
| 【一覧・詳細】 | 【内容】 | 【必須】 |
| 【OS 固有機能】 | 【例: カメラ、位置情報、Bluetooth、ウィジェット、通知、バックグラウンド処理】 | 【必須】 |

## OS 固有の要件

- 権限: 【必要な権限と、ユーザーに表示する説明文(利用目的)】
- バックグラウンド動作: 【必要 / 不要。必要なら内容と OS の制約を説明してほしい】
- 通知: 【ローカル / プッシュ(APNs / FCM)】
- 端末対応: 【iPhone のみ / iPad も / 折りたたみ・タブレット】
- ダークモード、動的な文字サイズ、多言語対応: 【対応する / しない】

## データ・通信

- 保存: 【端末内(SwiftData / Core Data / Room / DataStore など)/ サーバー】
- API: 【仕様書の場所 / これから設計】
- オフライン: 【必要 / 不要】
- 機密データ: 【Keychain / Keystore などの安全な保存先を使う】

## 品質要件

- テスト: ユニットテスト(ロジック)、UI テスト(主要フロー)
- アクセシビリティ: VoiceOver / TalkBack、文字サイズ、コントラスト
- 性能: 起動時間、スクロール、メモリ、バッテリー消費
- ストアの審査基準・プライバシー表示(データ収集の申告)に沿った実装

## 完了条件

- [ ] 必須機能が、対象 OS のシミュレーター/エミュレーターと実機で動作する
- [ ] ビルドが通り、テストが通り、警告が整理されている
- [ ] 権限の拒否・通信失敗・空データ・バックグラウンド復帰が確認できる
- [ ] 画面サイズ・向き・文字サイズを変えても崩れない
- [ ] ビルド手順と実行手順が `README` にある
- [ ] (ストア公開の場合)アイコン、スクリーンショット、署名、プライバシー情報が整理されている

## 進め方

1. まず「環境確認 → 要件の質問 → 画面遷移図 → アーキテクチャ・データ層の方針 → 作業ステップ」を提示して承認を待ってください。
2. 承認後、**OS ごとに 1 画面ずつ**(UI → 状態管理 → データ → テスト)実装してください。両 OS の場合は、先に片方を完成させてから次へ進みます。
3. 各ステップで、ビルド・実行方法とテスト結果を示してください。
4. 実機での確認、証明書・プロビジョニング、ストア操作など、私が行う作業は手順を明示してください。
