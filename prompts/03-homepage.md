# ホームページを作ってください

## 基本情報

- 組織・店舗名: 【名称】
- 業種・事業内容: 【一言で】
- サイトの目的: 【例: 信頼の獲得 / 来店・問い合わせの増加 / 採用 / 情報提供】
- 想定する閲覧者: 【お客様 / 求職者 / 取引先 など】

## サイトマップ

<!-- 不要なページは削除、足りないものは追加。提案を求めてもよい -->
- トップ
- 会社概要 / 店舗情報(住所、地図、アクセス、営業時間)
- サービス・商品紹介(【ページ数 / 一覧 + 詳細】)
- 実績・事例
- お知らせ / ブログ【ある / ない】
- 採用情報【ある / ない】
- お問い合わせ(フォーム)
- プライバシーポリシー

## 更新・運用

- 更新する人: 【開発者のみ / 非エンジニアのスタッフも】
- 更新頻度と対象: 【例: お知らせを月2回】
- 更新方法: 【ファイル編集 / Markdown / CMS(Headless CMS など)/ 未定(提案してほしい)】
- 公開先・ドメイン: 【例: 既存ドメイン / 新規取得 / 未定】

## 技術

- 候補: 【静的サイトジェネレーター(Astro、Eleventy など)/ Next.js / WordPress / 未定】
- 提案が必要なら、更新担当者・予算・保守の手間を踏まえて 2 案を比較してください
- 共通部分(ヘッダー・フッター)はコンポーネント/テンプレートにして重複させない

## デザイン

- 雰囲気・ブランドカラー・ロゴ: 【提供済み(場所: ○○)/ 未定】
- 参考サイト: 【URL 数件と、どこが好みか】
- 画像・写真: 【提供済み / プレースホルダー】
- レスポンシブ: スマホ・タブレット・PC に対応

## 機能

- お問い合わせフォーム: 【項目、送信先、迷惑メール対策(例: reCAPTCHA など)】
- 地図: 【Google Maps 埋め込み など】
- 多言語: 【なし / 日本語 + 英語】
- 検索・SNS 連携: 【なし / あり(○○)】

## 品質要件

- SEO: ページごとの `title` / `meta description`、見出し構造、`sitemap.xml`、`robots.txt`
- OGP とファビコン
- アクセシビリティ(コントラスト、`alt`、キーボード操作)
- 表示速度(画像最適化)
- 法的表記: プライバシーポリシー、(必要なら)特定商取引法表記、Cookie/計測の同意

## 完了条件

- [ ] 全ページがリンクでつながり、リンク切れがない
- [ ] PC・タブレット・スマホで表示が崩れない
- [ ] 問い合わせフォームが動く(正常系・入力エラー)
- [ ] 更新手順(誰がどう更新するか)が `README` にまとまっている
- [ ] 公開手順が示されている

## 進め方

1. まず「サイトマップ、技術の提案(2 案比較)、ページ別の内容案」を出して承認を待ってください。
2. 承認後、共通部分 → トップ → 下層ページ → フォームの順で実装し、各ステップで確認方法を示してください。
